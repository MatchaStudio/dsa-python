# Complexity Practice

## Questions Practiced

1. Single statement
   Answer: O(1)

2. Single loop
   Answer: O(n)

3. Two sequential n loops
   Answer: O(n)

4. Nested n loops
   Answer: O(n²)

5. n loop with fixed inner loop
   Answer: O(n)

6. Loop with i *= 2
   Answer: O(log n)

7. n loop × log n loop
   Answer: O(n log n)

## Key Learning

Nested loops do not automatically mean O(n²).
Always determine how many times each loop actually runs.
