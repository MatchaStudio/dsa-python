# Complexity Analysis

## Big-O

O(1) - Constant
O(log n) - Logarithmic
O(n) - Linear
O(n log n) - Linearithmic
O(n²) - Quadratic

## Important Patterns

One loop → O(n)
Nested n loops → O(n²)
n loop × log n loop → O(n log n)
Sequential loops → Add complexities and keep the dominant term
Fixed inner loop → Does not add another n
Repeated multiplication/division → O(log n)

## Space Complexity
Extra memory that grows with n → O(n)
Fixed extra memory → O(1)
